# Contributing to Corelux

## Introdution
Hi, my name is Michael Thomas, and I am a part-owner and the Chief Operating Officer here at Corelux. This file is intended for anyone who would like to contribute to Corelux. Before I begin, please note that this policy only applies to our HTML sites that use GitHub as a storage site. If you are editing the Google site or another HTML site that doesn't use GitHub, then please contact corelux.unblocking@gmail.com. If you are a staff member, then contact your direct supervisor instead of corelux.unblocking@gmail.com .

As with most computer files publicly maintained by the users of the internet, there is a set way to contribute to Corelux. Following this process is essential so that Corelux runs as intended. After these next few sentences you will find 2 other sections with information on how to contribute. One of them is for members and one of them is for staff members. Please make sure you are following the right set of instructions, failure to do so could lead to the failure of the site as well as disciplinary action.

## How to Contribute | Members
1. Fork our [GitHub repo.](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo)
2. Make your changes on the forked repo.
3. Make sure that your changes comply with our code of conduct, contributing policy, and securty policy.
4. Make a pull request from your [forked repo.](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request-from-a-fork) to our repo. <br>
  4a. If the PR fixs a then issue please include "[closing keywords](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/linking-a-pull-request-to-an-issue)".
5. Your done.
